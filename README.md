# SlovAr

SlovAr je edukativna web igrica izrađena u Reactu i Viteu. Namijenjena je djeci od 1. do 4. razreda osnovne škole, posebno učenicima s ADHD-om i/ili disleksijom.

Igrica kroz mirnu temu “Slovne galaksije” pomaže djeci vježbati slova, riječi, slušanje, pamćenje i pažnju.

## Pokretanje projekta

U terminalu pokrenite:
```bash
npm install
npm run dev

Igre u aplikaciji
Čuj slovo — aplikacija izgovori slovo, a dijete odabire točno slovo.
Spoji riječ i sliku — dijete sluša riječ i bira odgovarajuću sliku.
Memorijski niz — dijete sluša niz slova i ponavlja ga pravilnim redoslijedom.
Stop-Go fokus — zeleno znači klikni, crveno znači pričekaj.

Prilagodbe za ADHD
Na ekranu je prikazan samo jedan zadatak.
Upute su kratke i jasne.
Gumbi su veliki i lako uočljivi.
Povratne informacije su mirne i pozitivne.
Animacije su spore i nenametljive.

Prilagodbe za disleksiju
Koristi se velik i čitljiv font.
Tekst je kratak, jasan i visokog kontrasta.
Upute se mogu poslušati pomoću gumba za slušanje.
U postavkama se može povećati tekst i uključiti jači kontrast.
Nagrade i napredak

Dijete skuplja zvjezdice za točne odgovore. Napredak se sprema u preglednik pomoću localStorage memorije.

Spremaju se:

odabrana razina
ukupan broj zvjezdica
završene igre
osvojene značke
zvjezdice po pojedinoj igri

```
